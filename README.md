# 游戏指南

## 游戏简介
本项目是一款使用 Rust 与 Macroquad 引擎编写的 2D 炮战小游戏。玩家在可破坏的地形上轮流操作角色，通过蓄力发射弹药或使用喷气背包等技能，在限定时间内击败其他玩家。游戏支持 1~5 名玩家参与对战。

## 快速开始
1. 安装 Rust 开发环境（建议使用 rustup）。
2. 在项目根目录执行以下命令编译并运行游戏：
   ```bash
   cargo run
   ```
3. 进入游戏后，在开始菜单点击按钮或按下 `Enter` 进入玩家数量选择界面。

## 游戏流程
- **开始菜单**：点击按钮或按 `Enter` 进入玩家选择。
- **玩家选择**：通过鼠标选择 1~5 名玩家，游戏将重新载入地图并进入战斗。
- **战斗阶段**：玩家按照顺序轮流操作，进行移动、瞄准、蓄力与发射。
- **结算阶段**：当仅剩一名玩家存活时，进入胜利界面，可按 `Enter` 或点击返回主菜单。

## 基本操作
| 操作         | 键位 / 鼠标                    | 说明 |
|--------------|---------------------------------|------|
| 水平移动     | `A` / `D` 或 `←` / `→`          | 控制角色在地面上左右移动，速度会进行平滑过渡。 |
| 调整射击角度 | `↑` / `↓`                       | 在当前地面坡度下微调炮口角度，角度被限制在安全范围内。 |
| 蓄力发射     | 按下 `Space` 开始蓄力，松开发射 | 蓄力条位于屏幕上方中央，释放后发射弹药或触发喷气背包。 |
| 技能切换     | 点击屏幕右下技能按钮            | 鼠标点击切换技能状态，灰色代表不可用或未选择。 |
| 菜单确认     | 鼠标左键或 `Enter`              | 在菜单或结算界面确认操作。 |

## 技能系统
玩家可通过右下角的按钮配置技能组合，按钮上会显示技能名称或剩余次数。技能间的组合存在一定限制，以下为各技能效果：
- **Jetpack（jet）**：将本回合改为喷气背包冲刺。松开 `Space` 后角色会沿当前瞄准方向飞行一段距离，不再发射弹药。选择喷气背包会清除其他技能。
- **Heavy（heavy）**：强化弹药伤害。最多可叠加 2 次，分别使爆炸伤害提升至 1.5 倍与 2.0 倍。
- **Triple（consecutive）**：添加连续齐射。第一次添加会在 0.5 秒间隔内连续发射 3 轮，第二次添加会扩展至 5 轮。
- **Scatter（scatter）**：在基础角度附近添加 ±5° 的散射。可与 Heavy 或 Triple 组合，产生范围打击效果。

> 说明：喷气背包与其他技能互斥，Heavy 与 Triple 可分别叠加两次，Scatter 只能存在一份。

## 回合机制
- 每位玩家拥有固定回合时长（默认 20 秒）。若回合内未发射或结束动作，时间耗尽后直接切换至下一名存活玩家。
- 当玩家发射弹药或使用喷气背包后，需等待所有子弹命中或技能效果结束才会进入下一回合。
- 倘若当前玩家死亡，其回合立即结束，系统会自动选取下一位存活玩家。

## 地形与伤害
- 地图由 CSV 网格生成，绿色与浅灰色方块代表可破坏地形。
- 弹药命中地形或玩家时会产生炸坑，削弱地形并对附近玩家造成伤害。
- 伤害随距离衰减：越接近爆心伤害越高，远离则伤害减小至 0。
- 玩家生命值以血条与百分比显示在角色上方，归零后角色会倒下并失去行动能力。

## 常用配置
部分核心参数可以在 `src/config.rs` 中调整：
- 地图尺寸与瓦片大小（`ROWS`、`COLS`、`TILE_SIZE`）。
- 角色移动、跳跃与重力相关参数（`MOVE_SPEED`、`GRAVITY` 等）。
- 弹药与爆炸设置（`PROJECTILE_RADIUS`、`EXPLOSION_DAMAGE`、`EXPLOSION_RADIUS`）。
- 回合时长与蓄力速度（`TURN_DURATION`、`POWER_RATE`）。

调整后请重新编译运行，以便游戏使用新的配置。

## 调试建议
- 可以通过"src/map.py"修改 `src/map.csv` 自定义地形布局，构建不同的战术场景。
- 若需观察技能效果，推荐在双人对战中选用不同组合进行测试。
- 使用 `cargo check` 检查编译状态，`cargo fmt` 保持代码风格一致。

祝你游戏愉快！

## 联机玩法（每台电脑控制一个角色）

本次更新新增了一个极轻量的局域网控制通道：

1. **主机**运行完整游戏窗口，并通过 `--listen` 参数开放 UDP 端口。
2. **控制端**运行新的 `controller` 二进制，通过键盘发送自己的操作指令。
3. 游戏仍是回合制，所有玩家只需共享主机画面（面对面、屏幕共享等），即可在自己的电脑上完成操控。

### 启动主机

```bash
cargo run -- --listen 0.0.0.0:6000
```

- 进入游戏后像以往一样选择 1~5 名玩家。
- 0 号槽位始终由主机本地键鼠控制，其余槽位（1~N）可由远程控制端加入。
- 端口被占用时，程序会在终端提示，请更换端口后重试。

### 启动远程控制端

```bash
cargo run --bin controller -- --server 192.168.0.10:6000 --slot 2 --name Alice
```

- `--slot`：希望占用的玩家槽位（≥1，省略则自动分配空位）。
- `--name`：可选昵称，不填则默认使用操作系统用户名。
- 控制键位与本地基本一致：`A/D` 左右移动，`↑/↓` 调角度，`Space` 蓄力射击，`1~4` 切换喷气/重型/连射/散射技能。

> ⚠️ 联机模式只同步输入，不同步画面。请确保每位玩家都能看到主机屏幕，以便判断地形和时机。

### 断线与重新加入

- 控制端若 5 秒内无任何网络包，主机会自动释放该槽位，方便重新连接。
- 返回主菜单重新开局时，主机会重新分配所有槽位，控制端需要再次加入。
